1. HERO SECTION: กลุ่มรูปโปรไฟล์วงกลม (AVATAR GROUP)
==================================================
- **จุดแก้ไข:** บริเวณ Banner ด้านบนสุดของหน้าแรก ข้างๆ ข้อความ "5000+ นักเรียนไว้วางใจ" และดาว 5 ดวง
- **รายละเอียดการเปลี่ยนรูป:**
  - เปลี่ยนลิงก์รูปภาพ (`src`) ของโปรไฟล์วงกลมซ้อนกันทั้ง 4 รูป จากชาวต่างชาติเป็น **รูปใบหน้าคนไทยหรือคนเอเชีย (Asian Faces)** ที่ยิ้มแย้ม เป็นมิตร ดูเป็นธรรมชาติ
  - หากใช้บริการ Unsplash/Pexels ให้ใช้ Keyword: `thai person portrait`, `asian student face`, หรือ `asian smiling portrait`
  - เพิ่ม Comment ในโค้ดกำกับไว้สั้นๆ เช่น: `<!-- เปลี่ยนเป็นลิงก์รูปหน้าคนไทย 1, 2, 3, 4 -->` เพื่อความสะดวกในการมาเปลี่ยน URL รูปภาพในภายหลัง
- **การจัดแต่ง CSS:** คงลักษณะดีไซน์เดิมไว้ (รูปวงกลม `border-radius: 50%`, ขอบสีขาวหนาเล็กน้อย และวางซ้อนกัน Overlap อย่างสวยงาม)

2. HOMEPAGE TESTIMONIALS: การ์ดรีวิวในหน้าแรก
==================================================
- **เปลี่ยนรูปภาพโปรไฟล์ (Avatars):** ยกเลิกการใช้รูปภาพชาวต่างชาติ (Western/Caucasian) ทั้งหมดในการ์ดรีวิวหน้าแรก เปลี่ยนเป็น **นายแบบและนางแบบคนไทย/เอเชีย** ลุคสดใส สมจริง ไม่เน้นงาน AI สังเคราะห์ผิวพลาสติก
- **อัปเดตข้อมูลผู้รีวิว:** เปลี่ยนชื่อเล่น/ชื่อ-นามสกุล เป็นชื่อไทยสอดคล้องกับรูปภาพ (เช่น พี่นนท์, น้องฟ้า, คุณเอก) พร้อมระบุสถาบัน คอร์สเรียน และระยะเวลาให้สอดคล้องกับความเป็นจริง

4. MEDIA HANDLING & CSS STYLING
==================================================
- **อัปเดตลิงก์ไฟล์:** แก้ไข URL รูปภาพในไฟล์ Mock Data (เช่น `mockData.ts`, `data/reviews.json`, หรือ `Testimonials.jsx`)
- **การใช้ Stock Photos:** ค้นหาภาพด้วย Keyword ประเภท `Thai student candid`, `Asian university student casual outdoor`
- **การตั้งค่า CSS:** กำหนด `object-fit: cover;` บนทุกแท็ก `<img>` ที่เกี่ยวกับ Avatar และ Cover Image ของการ์ดรีวิว เพื่อให้รูปภาพปรับขนาดสมส่วน ไม่เบี้ยวหรือยืดขยายผิดอัตราส่วน
