Fix Mobile Responsive Issues – School Detail Pages

Please perform a complete audit and fix all mobile responsive issues on the school detail pages of the website.

Currently, when viewing the website on a mobile device, several sections are either cut off, collapsed incorrectly, or cannot be interacted with.

The goal is to ensure that all information is fully visible and accessible on desktop, tablet, and especially mobile devices.

Issues to Fix
1. Accommodation Section
Display all room types.
Display all room photos.
Display all room descriptions.
Display room prices correctly.
Ensure the section does not cut off after the first few items.
Users should be able to scroll through all accommodation information.
2. Facilities Section

Currently, only part of the facilities are shown.

Please:

Display every facility stored in the database.
Display all facility icons/images.
Show the complete facility description.
Ensure nothing is hidden on mobile.

Users cannot view all images on mobile.

Please:

If Accommodation, Facilities, Courses or Gallery use Tabs or Accordions,

Please ensure:

Every tab opens correctly.
Every accordion expands correctly.
No JavaScript errors.
