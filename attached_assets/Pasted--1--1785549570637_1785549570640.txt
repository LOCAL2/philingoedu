กฎการทำงาน (ห้ามฝ่าฝืน ใช้กับทุกข้อด้านล่าง):
1. ทำทีละข้อตามลำดับที่ระบุ ห้ามข้าม ห้ามทำสลับลำดับ
2. แต่ละข้อ ทำเสร็จแล้วต้อง: แสดง diff → deploy → ทดสอบด้วยตัวเอง (ไม่ใช่แค่บอกว่าเสร็จ) 
   → รายงานผลพร้อมหลักฐาน → แล้วค่อยไปข้อถัดไป
3. ห้ามแก้ไฟล์ที่ไม่เกี่ยวข้องกับข้อที่กำลังทำ
4. ทุกข้อที่เกี่ยวกับมือถือ ต้องทดสอบที่ 375px และ 390px จริงก่อนบอกว่าเสร็จ
5. ห้ามพูดว่า "แก้แล้ว" โดยไม่มี diff + ยืนยัน deploy + ผลทดสอบจริง

═══════════════════
ข้อ 0 (ทำก่อนสิ่งอื่นทั้งหมด): ยืนยันสถานะข้อมูลรีวิว
═══════════════════
Query ฐานข้อมูลจริง (heliumdb) นับแถวในตาราง reviews/blog_posts ที่ category='review'
- ถ้ายังไม่ครบ 10 แถว ให้กู้คืนให้เสร็จสมบูรณ์ก่อน แล้ว deploy และเปิดเว็บจริงเช็คว่าขึ้นครบ
- รายงานผลก่อนไปข้อถัดไป

═══════════════════
ข้อ 1: Banner หน้าแรกกิจกรรม คลิกไม่ได้
═══════════════════
- หา component banner ในหน้าแรก เช็คว่าไม่มี onClick/href, หรือมี element บัง (z-index/pointer-events)
- แก้ให้คลิกแล้วไปหน้ากิจกรรม/ลงทะเบียนได้จริง

═══════════════════
ข้อ 2: หน้ากิจกรรมใน Landing Page ไม่อัปเดตบนมือถือ (เปลี่ยนเองไม่ใช้ค่าที่ตั้งไว้)
═══════════════════
- เช็คว่ามี component แยกกันระหว่าง Desktop/Mobile หรือไม่ (เช่น ไฟล์ ActivityDesktop / ActivityMobile)
- ถ้ามี ให้รวมเป็น component เดียวที่ responsive ด้วย CSS แทน ไม่ใช่แยกไฟล์คนละตัว
- ตรวจว่ามี cache (build/service worker/CDN) ที่ทำให้มือถือค้างเวอร์ชันเก่าหรือไม่ ล้าง cache ที่จำเป็น
- ทดสอบ: แก้เนื้อหาหน้ากิจกรรม → deploy → เปิดมือถือจริง (Incognito) → ต้องเห็นค่าที่ตั้งไว้ ไม่เปลี่ยนเอง

═══════════════════
ข้อ 3: ตัวเลือกแผนเรียน/ห้องพัก/ระยะเวลา ต้องเป็น Dropdown
═══════════════════
- เปลี่ยนจากปุ่มเรียงแนวนอนที่ล้นจอ ให้เป็น <select> dropdown เต็มความกว้าง container
- สูงอย่างน้อย 44px กดง่ายบนมือถือ

═══════════════════
ข้อ 4: ปุ่มลอย (LINE/Messenger/TikTok/โทร) บังเนื้อหาสำคัญ
═══════════════════
- ยุบเป็น FAB ปุ่มเดียวกดขยาย หรือขยับตำแหน่งไม่ให้ทับตารางราคา/ปุ่ม action หลัก
- ทดสอบที่ 320-375px ว่าไม่บังอะไร

═══════════════════
ข้อ 5: ราคาประเมิน / ราคาโปรโมชั่น ล้นขวาจอมือถือ (ต้องเลื่อนซ้ายถึงเห็น)
═══════════════════
- แก้ container ให้ผลลัพธ์แสดงอยู่ใน viewport เสมอ ไม่ล้นขวา ไม่ต้อง scroll เพื่อดู

═══════════════════
ข้อ 6: ตารางเปรียบเทียบราคา และตารางเรียนรายวัน มองเห็นไม่หมด
═══════════════════
- ห่อด้วย container overflow-x: auto + -webkit-overflow-scrolling: touch
- เพิ่ม indicator บอกว่าลากดูต่อได้ (เงาขวา/ลูกศร)
- ห้ามกระทบ scroll ของทั้งหน้า

═══════════════════
ข้อ 7: วิดีโอ CIA ไม่แสดง (ใส่ URL ไปแล้ว)
═══════════════════
- เช็คว่า URL เป็น embed link ที่ถูกต้องหรือไม่ (ต้องแปลง YouTube link ปกติเป็น /embed/ ก่อน)
- เช็ค Console error เรื่อง CORS/embed ถูกปฏิเสธ

═══════════════════
ข้อ 8: หน้ารีวิว คลิกแล้วไม่มีข้อมูล / ไม่ตรงกับ Admin Panel
═══════════════════
- เช็คว่าหน้าเว็บกับ admin panel ดึงข้อมูลจาก source เดียวกันหรือไม่
- เช็ค cache ที่อาจทำให้ข้อมูลใหม่จาก admin ไม่อัปเดตหน้าเว็บ

═══════════════════
ข้อ 9: ระบบภาษา TH/EN ไม่จำค่าที่เลือกไว้ (reset กลับเป็น EN)
═══════════════════
- เพิ่ม localStorage เก็บค่าภาษาที่ผู้ใช้เลือก
- โหลดหน้าใหม่ทุกครั้งให้เช็ค localStorage ก่อน ไม่ให้ auto-detect จาก browser ทับค่าที่เคยเลือก
- ทดสอบ: เลือกไทย → refresh → เปลี่ยนหน้า → กลับมา ต้องยังเป็นไทย
