กฎการทำงาน (ห้ามฝ่าฝืน):
1. ทำทีละข้อ ทดสอบจริงบนมือถือ (viewport 428px สำหรับ iPhone 13 Pro Max) ก่อนบอกว่าเสร็จ
2. ห้ามบอกว่า "แก้แล้ว" โดยไม่มี screenshot/หลักฐานจริงจาก production
3. แสดง diff ก่อน apply ทุกข้อ

ข้อ 1: วิดีโอ YouTube ไม่แสดง (แก้มาหลายรอบแล้วไม่หาย)
═══════════════════════════════
1. หา field ที่ admin กรอก YouTube URL ในหน้าแก้ไขสถาบัน
2. เช็คทีละสาเหตุ:
   - URL ที่กรอกเป็นแบบ youtube.com/watch?v=xxx หรือเป็น embed URL youtube.com/embed/xxx
   - โค้ด frontend แปลง URL เป็น embed format อัตโนมัติหรือไม่ (ถ้า admin กรอกแบบปกติ 
     ระบบต้องแปลงเป็น embed เองอัตโนมัติ ไม่ใช่ให้ admin ต้องรู้วิธีแปลงเอง)
   - เช็คว่าค่า URL ที่กรอกไป บันทึกลง database จริงหรือไม่ (query ตรงเช็ค)
   - เช็ค Console error ตอนโหลดหน้าสถาบันที่มี field วิดีโอ
3. แก้ให้ admin กรอก URL แบบปกติจาก YouTube (copy มาจาก address bar ตรงๆ) แล้วระบบ
   แปลง/แสดงผลได้เองอัตโนมัติ ไม่ต้องให้ admin ทำอะไรเพิ่ม
4. ทดสอบ: กรอก YouTube URL จริงของ CIA → บันทึก → เปิดหน้า /schools/cia บนมือถือจริง 
   → วิดีโอต้องเล่นได้จริง ไม่ใช่กล่อง placeholder

═══════════════════════════════
ข้อ 2: เนื้อหาบทความ (จุดเด่น/รายละเอียด) ตัวหนังสือถูกบัง
═══════════════════════════════
1. หาส่วน "จุดเด่น" และเนื้อหาบทความในหน้าสถาบัน (เช่น "Semi-Sparta ได้ผลเร็ว")
2. เช็คว่าปุ่มลอย LINE (มุมขวาล่าง) บังข้อความส่วนนี้หรือไม่ (จากภาพเห็นปุ่ม LINE ทับ 
   ข้อความ "แคมปัสใหม่ระดับพรีเมียม")
3. แก้ padding/margin ให้เนื้อหาไม่โดนปุ่มลอยบัง เหมือนที่เคยแก้ในหน้า PriceCalculator 
   (ใช้วิธีเดียวกัน: เพิ่ม padding ขวา-ล่างเฉพาะจอมือถือ)
4. ทดสอบที่ 375px, 390px, 428px (iPhone 13 Pro Max) ว่าไม่มีข้อความไหนโดนบังอีก

═══════════════════════════════
ข้อ 3: ใส่โลโก้ด้านบนของทุกหน้าสถาบัน (ที่เคยส่งไฟล์ไปแล้ว)
═══════════════════════════════
1. เช็คว่าไฟล์โลโก้ที่เคยส่งไปมีอยู่ในระบบแล้วหรือยัง (ถามผู้ใช้ถ้าไม่แน่ใจตำแหน่งไฟล์)
2. เพิ่มโลโก้ Philingo ที่หัวของทุกหน้าสถาบัน (ไม่ใช่แค่ CIA หน้าเดียว ทุกสถาบันต้องมี)
3. จัดตำแหน่งให้เหมาะสม ไม่บังเนื้อหาอื่น ไม่ล้นจอมือถือ

═══════════════════════════════
ข้อ 4: หน้าจอไม่เต็มจอ ชิดซ้าย ดูเล็กบน iPhone 13 Pro Max
═══════════════════════════════
1. ทดสอบที่ viewport 428px (iPhone 13 Pro Max) โดยเฉพาะ ไม่ใช่แค่ 375/390px 
   ที่เคยทดสอบมาตลอด
2. เช็คว่ามี fixed width (px) ที่เล็กกว่าจอ 428px ทำให้เนื้อหาไม่เต็มความกว้างจอหรือไม่
3. เช็คว่า container หลักใช้ width: 100% หรือ max-width ที่เหมาะสม ไม่ใช่ width ตายตัวเล็กๆ
4. แก้ให้เต็มความกว้างจอทุกขนาด รวมถึง 428px นี้ด้วย

═══════════════════════════════
ข้อ 5: ปุ่ม "ขอใบเสนอราคา" สีน้ำเงิน มองไม่เห็น
═══════════════════════════════
1. หาปุ่มที่เกี่ยวข้องกับใบเสนอราคาในหน้าสถาบัน (เห็นในภาพ: "สร้างใบเสนอราคา" 
   เป็นปุ่มพื้นขาวตัวหนังสือน้ำเงิน อยู่ในกล่องสีน้ำเงินเข้ม)
2. เช็คว่าสีตัวหนังสือ/พื้นหลังปุ่มมี contrast พอมองเห็นชัดหรือไม่ 
   (ปุ่มพื้นขาวตัวหนังสือน้ำเงินอ่อน อาจกลืนกับพื้นหลังบางจุด)
3. แก้ให้ปุ่มนี้เห็นชัดเจน ใช้สีที่ contrast สูงขึ้น หรือเพิ่ม border ให้เด่นขึ้น

ข้อ 6: ย้ายปุ่ม "สร้างใบเสนอราคา" ไปอยู่ใกล้/บนส่วนประเมินราคา (เคยขอไปแล้วไม่ได้ทำ)
═══════════════════════════════
1. หาตำแหน่งปัจจุบันของปุ่ม "สร้างใบเสนอราคา" (ตอนนี้อยู่ล่างสุดของหน้า รวมกับปุ่ม 
   LINE/ปรึกษาฟรี)
2. ย้ายปุ่มนี้ไปอยู่ใกล้ หรือด้านบนของส่วน "ประเมินค่าใช้จ่าย" (PriceCalculator) 
   เพื่อให้ผู้ใช้เห็นและกดสร้างใบเสนอราคาได้ทันทีหลังจากดูราคาประเมิน
3. ยืนยันกับฉันก่อนว่าจะย้ายไปตำแหน่งไหนแน่ชัด (แสดง mockup/คำอธิบายตำแหน่ง) ก่อน apply จริง
4. ทดสอบว่าปุ่มนี้ยังทำงานได้ปกติหลังย้ายตำแหน่ง (กดแล้วสร้างใบเสนอราคาได้จริง)
