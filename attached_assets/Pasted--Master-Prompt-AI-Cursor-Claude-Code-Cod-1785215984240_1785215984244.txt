ถ้าคุณจะใช้เป็น **Master Prompt** สำหรับสั่ง AI ให้พัฒนาระบบเป็นรอบ ๆ (เช่น Cursor, Claude Code, Codex หรือ GPT) แนะนำให้เขียนแบบนี้เพื่อให้ AI เข้าใจขอบเขตงานชัดเจนและไม่ทำงานเกิน Phase

# Master Development Prompt (Phase-by-Phase)

พัฒนาระบบเว็บไซต์โดยแบ่งการทำงานออกเป็น 5 รอบ (Phase) อย่างชัดเจน โดยให้ดำเนินการเฉพาะงานของแต่ละ Phase เท่านั้น ห้ามข้ามไปทำงานของ Phase ถัดไปจนกว่าจะได้รับอนุมัติ

ทุก Phase ต้อง

* ใช้โครงสร้างโค้ดที่สะอาด (Clean Architecture)
* รองรับการขยายระบบในอนาคต
* แยก Frontend, Backend และ Database อย่างเป็นระบบ
* เขียนโค้ดตาม Best Practices
* มี Error Handling
* มี Validation ทุกฟอร์ม
* รองรับ Responsive Design
* มี Comment อธิบายเฉพาะส่วนสำคัญ
* ก่อนจบแต่ละ Phase ให้สรุปรายการไฟล์ที่สร้างหรือแก้ไข พร้อมอธิบายสิ่งที่ทำทั้งหมด

วัตถุประสงค์

สร้างโครงสร้างพื้นฐานของระบบทั้งหมด

งานที่ต้องทำ

* ออกแบบฐานข้อมูลทั้งหมด
* สร้าง ER Diagram
* สร้าง Database Schema
* Migration
* Seed Data
* สร้างระบบ Authentication
* Login
* Logout
* Forgot Password
* Reset Password
* Role Management
* Admin
* User
* Middleware
* Session / JWT
* Password Hash
* Protected Route
* Admin Login Page
* Dashboard Layout (โครงสร้างเปล่า)
* Environment Configuration
* API Structure

เมื่อเสร็จแล้วให้สรุป

* Database Structure
* API List
* Folder Structure
* วิธีติดตั้ง

จากนั้นหยุดรอคำสั่ง
