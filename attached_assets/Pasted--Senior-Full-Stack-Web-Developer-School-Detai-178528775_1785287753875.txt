### 1. ระบบประเมินค่าใช้จ่ายอัตโนมัติ (Universal Cost Estimator Component)
ให้ใช้ Component นี้เป็น Template มาตรฐานเดียวกันในทุกๆ หน้ารายละเอียดสถาบัน:

- **การดึงข้อมูลอัตโนมัติ (Data-Driven):**
  - ดึงข้อมูลจากฐานข้อมูล Price List และ Local Fee ของสถาบันนั้นๆ ที่ Admin อัปโหลดไว้
  - ระบบจะคำนวณยอดเงินรวมให้อัตโนมัติทันทีที่ผู้ใช้เปลี่ยนตัวเลือก (Dynamic Calculation)

- **ตัวเลือกคำนวณ (Input Controls):**
  1. Dropdown "เลือกแผนการเรียน" (เช่น ESL ปกติ, ESL เข้มข้น, IELTS, TOEIC, Business English)
  2. Dropdown "เลือกห้องพัก" (เช่น ห้อง 4 คน Quad, ห้อง 3 คน Triple, ห้องคู่, ห้องเดี่ยว)
  3. Selector "ระยะเวลา" (4 สัปดาห์, 8 สัปดาห์, 12 สัปดาห์, 16 สัปดาห์, 20 สัปดาห์, 24 สัปดาห์)

- **การแสดงผลตารางสรุปราคา (Bill Breakdown Display):**
  - แสดงบรรทัดแจกแจงรายการชัดเจน:
    - ค่าธรรมเนียมสมัคร / ค่าเล่าเรียน ($USD)
    - ค่าที่พัก + อาหาร ($USD)
    - ส่วนลด / Promotion (ตัวหนังสือสีเขียว แสดงเครื่องหมายลบ - $USD)
  - **สรุปรวมค่าโรงเรียน (ชำระล่วงหน้า):** แสดงยอดรวม $USD พร้อมแปลงเป็นเงินบาทสดๆ (≈ ฿THB)
  - **Local Fee (ชำระที่โรงเรียน):** แสดงยอดเงินเปโซ (₱PHP) เช่น ค่า SSP, Visa extension, ค่าไฟ, ID Card พร้อมแปลงเป็นบาท (≈ ฿THB)
  - **ยอดรวมทั้งหมด (ประมาณการ):** แสดงเป็นตัวเลขเงินบาทขนาดใหญ่เน้นชัดเจน (เช่น ฿67,875) และตัวเล็กระบุเป็นยอดรวมดอลลาร์ (≈ $USD)

### 2. ส่วนตารางเรียนรายวัน (Daily Schedule Component)
สร้างส่วนแสดงผลตารางเรียนรายวันตามสถาบันตัวอย่าง CIA:

- **Tab หลักสูตร (Course Tabs):** 
  - ด้านบนมี Tab ให้คลิกสลับดูตารางเรียนของแต่ละคอร์สได้ (เช่น ESL Regular, ESL Intensive, IELTS Prep, TOEIC)
  - แต่ละ Tab มี Badge ระบุจำนวนคาบ เช่น `1:1x4 | กลุ่มx4`

- **รายการตารางเวลา (Timeline Breakdown):**
  - แสดงการ์ดรายการเรียงตามเวลา (เช่น 07:00 - 08:00, 08:00 - 08:50)
  - ฝั่งขวาของการ์ดมี **Badge สีแบ่งประเภทกิจกรรม** ชัดเจน:
    - 🔵 สีน้ำเงิน = เรียน 1 ต่อ 1 (เช่น เรียน 1 ต่อ 1 ชั่วโมงที่ 1)
    - 🟢 สีเขียว = เรียนกลุ่ม (เช่น เรียนกลุ่ม ชั่วโมงที่ 1)
    - 🟡 สีเหลือง = อาหาร (เช่น อาหารเช้า, อาหารกลางวัน)
    - 🟣 สีม่วง = ติวเอง / ทบทวน
    - ⚪ สีเทา = เวลาว่าง / พักผ่อน

- **Sidebar ด้านข้าง:**
  - **การ์ดคำอธิบายสีตาราง (Legend Card):** สรุปความหมายของแต่ละสี
  - **การ์ดกฎของโรงเรียน (School Rules Card):** แสดงกล่องข้อความเตือนและกฎระเบียบสำคัญ (เช่น English Only Zone, เวลาเคอร์ฟิว 22:00 น., กฎการเข้าเรียน 100%)

### 3. โครงสร้างและการทำ Template สำหรับหลังบ้าน (Admin & System Architecture)
- **Reusable Component:** เขียนโค้ดส่วน Calculators, Schedule และ Gallery ให้เป็น Global Reusable Components เพื่อให้ทุกๆ สถาบัน (School ID) เรียกใช้งาน Layout และ Logic ชุดเดียวกันได้ 100%
- **Admin Input for Schedule:** เพิ่มช่องในหลังบ้าน ให้ Admin สามารถจัดการตารางเรียน (เพิ่ม/ลด คาบเวลา, เลือกประเภทกิจกรรม, ระบุประเภทคอร์ส) ของแต่ละสถาบันได้ง่าย
